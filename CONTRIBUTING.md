# Development

This repository is being prepared locally. Licensing and public collaboration
terms remain unresolved; it is not accepting public contributions yet.

For local changes:

1. Explain the behavior being changed and its impact on host integrations.
2. Add a reproducer for a defect or a behavioral test for a new contract.
3. Run `bash scripts/check.sh` with the pinned toolchain.
4. Update the example, limitations and architecture decision if they change.
5. Commit a coherent change with a factual message, such as
   `fix: retain reservations until completion`.

Do not add commits solely to generate activity. Do not imply future maintenance
or platform support has already been demonstrated.
